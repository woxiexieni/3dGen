**我做的技术诊断**（用 numpy 直接解 STL + 拆 GLB，不依赖 Blender）：
- 模型 49.99 万三角面，单 mesh 单材质，贴图 4096×4096
- **贴图是 AI 切碎的 atlas（几百块），脸上无任何五官像素** → 靠贴图修脸这条路彻底死，UV 也不行（碎片化）
- **四向正交投影验证：模型朝向标准（脸朝 -Y，Numpad 1 即正面）**。之前预览图看着"侧身"是渲染相机 45° 斜侧机位，不是姿势错
- 真问题：**头侧转 15-20°**（正视图脸偏右）、脸型偏长下巴尖、**胸前两条粗辫子**（照片是披肩长卷发）、裙褶被磨平、手糊成一坨、包链条过细
- 比例：总高 1.1644，头顶到下巴约 16%（含发），约 6.2-6.5 头身，偏可爱但接近本人

**核心结论**：单图 AI 的"不像"里，70% 在头发。脸在 15cm 尺度（头高 23mm、脸宽 15mm、眼宽 3mm）根本印不出五官 → **只改轮廓，五官靠涂装**。终局工艺建议「光固化素模 + 代涂」，比全彩打印像得多。

## 追加：女友 iPhone 可拍环绕视频 → 扫描路线方案（已交付）

**背景**：用户女友用 iPhone，可配合拍 3 分钟环绕视频。用户问「扫描出来怎么和 v2 结合」。

**关键计算（说服力核心）**：真人身高 1620mm → 手办 150mm，比例 0.0926。
脸宽 140mm→13mm、鼻梁高 15mm→1.4mm、眼窝深 8mm→0.74mm；
手机扫描精度 1-2mm → 缩放后 0.09-0.19mm，**远低于光固化 0.05mm 层高的表现下限**。
→ **结论：瓶颈不在扫描精度，在打印工艺。手机扫描的脸对 15cm 手办绰绰有余。**

**核心判断**：扫描赢在「数据真实」（体形/姿态/服装褶皱/脸部凹凸），输在「网格质量」和「头发」（糊块+漂浮噪点）。
→ 结合方式不是替换，是 **用扫描提供准确数据、用 v2 提供可打印的干净壳子**。

**三条路线**：
- A（推荐先做，1-1.5h）扫描当标尺：两个模型都归位到 150mm/脚底 z=0/原点居中 → 扫描设为 Wire 半透明 → 三视图叠加 → 雕刻 Grab 对着拉 v2（清单：头朝向→肩宽→裙摆高度→腿粗→脸型→头发体积→包位置）。不破坏 v2，零风险。
- B（要脸真像，2-3h）切头换头：清理扫描只留脸+脖 → v2 环选脖子断开 → 删头 → Bridge Edge Loops 桥接（失败则 Ctrl+J + Voxel Remesh 0.25mm）→ 头发用 v2 的块面盖住。
- C（全用扫描）仅当扫描完整、无大洞、头发成块。

**工具推荐**：Kiri Engine（免费额度大、中文、支持视频导入）> Polycam（精度好但付费+网络）> Meshroom/RealityCapture（本地需 N 卡）。
LiDAR 机型：iPhone 12 Pro 及以后 Pro/Pro Max。有则开 LiDAR 辅助救白色衣物。

**拍摄硬标准**：穿照片同款衣服 + 同发型 + 4K30 视频绕两圈（胸高/眼高各一圈，每圈约 40s）+ 补拍 20-30 张照片；漫射光、禁直射阳光；人必须静止 2-3 分钟（否则鬼影废脸）。
